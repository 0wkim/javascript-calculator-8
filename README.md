# 프리코스 1주차 미션 - 문자열 덧셈 계산기
-----------------

## 기능 목록

### 구분자 기준으로 숫자 분리
- 사용자가 입력한 값을 받아 변수에 저장한다.

- 구분자 종류
    1. 쉼표
    2. 콜론
    3. 커스텀 구분자

- 위의 구분자들을 기준으로 숫자를 분리하여 숫자가 잘 분리 되었는지 console창에 출력하여 확인한다.

- 만약 커스텀 구분자를 만들었을 경우, //와 \n 사이의 구분자 값을 저장한다. 이후 사용자가 입력한 문자열에서 해당 구분자와 같은 값이 있으면 그 값을 기준으로 숫자를 분리한다.

- 한 문자열에 커스텀 구분자와 일반 쉼표, 콜론 구분자가 모두 써진 경우, 세종류의 구분자에 따라서 모두 분리한다.

- 사용자의 입력에 공백이 포함된 경우, 공백은 제거한다. 단, 커스텀 구분자 안에 공백이 있는 경우는 앞뒤 공백만 제거한 후 공백을 구분자로 사용한다.

- 한 문자열에 여러개의 커스텀 구분자가 존재하는 경우, 구분자 배열에 담아서 사용한다.

### 숫자의 합 계산

- 분리 된 숫자를 모두 합한다.

- 최종 계산 된 결과를 출력한다.

### 예외처리

- 사용자가 잘못된 값을 입력하는 경우
    1. 구분자와 양수가 아닌 다른 값을 입력 
    2. 구분자만 입력

- [ERROR]로 시작하는 메시지를 띄우고 Error를 발생시킨다.
    1. [Error] 계산할 수 없는 값이 입력되었습니다. 구분자와 양수만 사용해주세요.
    2. [Error] 숫자가 입력되지 않았습니다. 구분자 사이에 숫자를 입력해주세요.

- Error가 발생된 후 애플리케이션은 종료한다. 
    ex) "프로그램이 종료되었습니다."
