# 프리코스 1주차 미션 - 문자열 덧셈 계산기
-----------------

## 기능 목록

### 구분자 기준으로 숫자 분리
- 사용자가 입력한 값을 받아 변수에 저장한다.

- 구분자 종류
    1. 쉼표
    2. 콜론
    3. 커스텀 구분자
        - 커스텀 구분자는 '문자'이므로 한 글자일 것

- 커스텀 구분자를 만들었을 경우, //와 \n 사이의 구분자 값을 저장한다. 이후 사용자가 입력한 문자열에서 해당 구분자와 같은 값이 있으면 그 값을 기준으로 숫자를 분리한다.

- 한 문자열에 커스텀 구분자와 일반 쉼표, 콜론 구분자가 모두 써진 경우, 세종류의 구분자에 따라서 모두 분리한다.

- 사용자의 입력에 공백이 포함된 경우, 공백은 제거한다. 단, 커스텀 구분자 안에 공백이 있는 경우는 앞뒤 공백만 제거한 후 공백을 구분자로 사용한다.

- 한 문자열에 여러개의 커스텀 구분자가 존재하는 경우, 커스텀 구분자 배열에 담아서 사용한다.

### 숫자의 합 계산

- 분리 된 숫자를 모두 합한다.

- 최종 계산 된 결과를 출력한다.

### 예외처리

- 예외처리 상황
    1. 구분자와 양수가 아닌 다른 값을 입력
    2. 커스텀 구분자 내에 문자가 2개 이상
    3. 입력값으로 0을 받음
        - 단, 커스텀 구분자로 0이 쓰인 경우는 해당하지 않음
        - 0으로 시작하는 소수점일 경우, 양수이므로 해당되지 않음 (0.3, 0.4 등)
    4. 음수를 입력

- [ERROR]로 시작하는 메시지를 띄우고 Error를 발생시킨다.

- Error가 발생된 후 애플리케이션은 종료한다.
